# ![](images/main.svg) TECNICAS DE RECOLECCION DE INFORMACION

- ![](images/fundamento.svg)
Fundamento: recopilar necesidades, 
expectativas y requisitos del cliente


- Técnicas
    - ![](images/entrevista.svg)
    Entrevista
        - conversación rígida
        enmarcada en un guión
        acude a la fuente directa
        para recopilar la info.
        - Se debe preparar cuestionario
        elegir lugar adecuado, hacer
        sentir cómodo al entrevistado
        - Se pueden usar preguntas
        abiertas o cerradas
    - ![](images/encuesta.svg)
    Encuesta
        - Recopila información, datos
        y comentarios
        - Se requiere un muestreo
        representativo (rigor estadístico)
    - ![](images/cuestionario.svg)
    Cuestionario
        - Serie de preguntas ordenadas
        - De aplicación rápida
        - ayuda a determinar comportamientos
        tendencias y posturas
        - Suele percibirse muy simple

    - ![](images/observacion_directa.svg)
    Observación directa
         - Observar el proceso directamente
         - Observador no debe participar
         en el proceso
         - larga duración
         - observados deben actuar 
         naturalemente
    - ![](images/focus_group.svg)
    Focus Group
        - Busca conocer opiniones sobre un
    producto o servicio
        - Usa la experiencia real de 
        los participantes para validar
        - roles
            - moderador: regula
            - relator: recopila información
            - grupo investigador: implementan la medotodología
            - participantes: aportan la información
